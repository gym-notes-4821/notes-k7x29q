# Trainingsapp

Deutschsprachige, offline-fähige Trainings-Web-App fürs iPhone (ohne Build-Schritt, ohne externe Bibliotheken).
Daten liegen nur im localStorage des Geräts – Sicherung über „Trainingspläne › Daten exportieren“.


Tests: `node tests/logic.test.js` (ohne Abhängigkeiten); `tests/ui.test.js` benötigt Playwright.
